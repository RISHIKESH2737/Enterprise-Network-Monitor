# Enterprise Network Monitor

A professional, Python-based network monitoring dashboard designed for real-time uptime tracking and smart alerting.

---

## Technical Stack
* **Core:** Python, Flask
* **Concurrency:** Multi-threading for parallel network scanning
* **Data & Config:** JSON configuration, CSV reporting, and detailed log files

---

## Features
* **Real-Time Monitoring:** Live tracking of device status and response times via a clean Flask web dashboard.
* **High-Performance Scanning:** Multi-threaded architecture ensures fast, non-blocking pings across multiple targets.
* **Smart Alert System:** Automated outage detection that intelligently catches downtime and sends recovery notifications.
* **Robust Reporting:** Automatically generates persistent CSV reports and structured log files for historical analysis.
* **Config-Driven Architecture:** Easily manage and scale monitored devices via a simple JSON configuration.
