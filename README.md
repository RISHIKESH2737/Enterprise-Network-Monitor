# Enterprise Network Monitor

Real-time infrastructure monitoring dashboard built with:

- Python
- Flask
- Flask-SocketIO
- SQLite
- Chart.js
- Multithreading

## Features

- Real-time device monitoring
- Live WebSocket updates
- Historical analytics
- Search filtering
- Responsive dashboard
- Online/offline tracking
- SQLite logging

## Tech Stack

- Backend: Flask + Python
- Frontend: HTML/CSS/JS
- Database: SQLite
- Realtime: SocketIO

## Installation

```bash
pip install -r requirements.txt
python app.py
```
