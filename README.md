# Enterprise Network Monitor

A professional Python-based network monitoring dashboard built using:

- Python
- Flask
- Multi-threading
- JSON configuration
- CSV reporting
- Smart alert system

## Features

- Real-time network monitoring
- Live Flask dashboard
- Multi-threaded scanning
- Response time tracking
- CSV and log reporting
- Smart offline/recovery alerts

## Installation

pip install -r requirements.txt

## Run

python app.py
